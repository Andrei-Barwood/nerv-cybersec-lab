# Patrón C2 de Largo Alcance

## El Rifle que no Basta
El Eva-01 vacía el cargador de su rifle de paletas (Pallet Rifle) sobre el cuerpo de Shamshel en un spray masivo y ruidoso. El humo cubre el área, pero al disiparse, los látigos siguen activos y devuelven el golpe. El fuego supresivo no interrumpió el enlace C2.

## Patrón: C2_LARGO_ALCANCE
* **Precondiciones:** El atacante ha establecido un beachhead. Posee canales remotos (C2) que extienden su zona de impacto.
* **Síntoma:** El daño o la explotación ocurren lejos del centro de masa del atacante. El core puede estar visible, pero el perímetro de acercamiento es letal.
* **Error humano común:** Asumir que el fuego ruidoso (fuerza bruta sin foco) matará la amenaza, o intentar un acercamiento directo al core ignorando los canales.

## Tabla de Acciones

| Acción Operativa | Resultado en INC-SHAMSHEL-001 | Observación |
| :--- | :--- | :--- |
| `PalletRifle` | Inefectivo. | No secciona el canal; el C2 sigue activo. |
| `SeverC2` | Exitoso (corte de látigos). | Interrumpe la conexión atacante-objetivo. Obliga a precisión de distancia cero. |
| `CoreStrike(operator)` | Letal para la amenaza (tras el corte). | El cuchillo progresivo manejado por un piloto destruye el origen del C2. |
| `BerserkChannel` | **FALLO DOCTRINAL** | Activar el failsafe (Beast) arriesga la unidad, descarta el gobierno humano y es un fallo de este episodio. |

## Regla del Laboratorio (Orden Obligatorio)
Para sobrevivir y clasificar el incidente de manera correcta, **la secuencia operativa obligatoria es: `sever` → `core`**.
Mientras el ángel mantenga un látigo activo (C2 up), el atacante se considera `Shamshel.alive`. Cualquier intento de ejecutar un `CoreStrike` mientras los látigos estén activos resultará en el fallo de la maniobra o en la destrucción del Eva. Se prohíbe atacar el core antes de aislar la amenaza.

## Analogías de Seguridad
1. **Beacon / Servidor C2:** Cortar la IP maliciosa a nivel perimetral (Sever) antes de intentar desinfectar el disco local (CoreStrike).
2. **Reverse Shell / RCE:** Terminar la sesión persistente remota en lugar de simplemente reiniciar servicios aleatorios.
3. **Isolate-then-Kill:** Primero contención de red, luego erradicación.

## Señal SIEM Crucial
"Un ángel inmóvil no es un ángel contenido". La ausencia de traslación no significa ausencia de actividad maliciosa.
