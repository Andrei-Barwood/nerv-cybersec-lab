# Controles Preventivos: No depender del Sysadmin Modo-Dios

## Preventivo vs. Solo Mitigable

El Episodio 20 es en sí mismo una larga operación de mitigación a los fracasos preventivos del 19.

| Controles PREVENIBLES (Evitando disolver al L1) | Controles SOLO MITIGABLES (El Retorno y la Deuda) |
| :--- | :--- |
| **No Ingerir 0-Days Hostiles:** Lo obvio. Si el 19 no hubiera forzado al analista a recurrir al Modo Bestia para tragarse el núcleo/S2 enemigo para sobrevivir a la sobrecarga, hoy no tendríamos el problema de un analista desintegrado de tanto correr como root. | **El Salvage (Reconstrucción Frágil):** Una vez que el analista está disuelto (Burnout nivel extremo), solo puedes intentar un `salvage` cauteloso y cruzar los dedos para que él quiera `return_to_body`. |
| **Separación de Roles vs Tool Merge:** Fomentar una cultura corporativa donde los analistas entiendan que ellos *NO SON* las máquinas que operan (Boundaries/AT Field sólidos), previene la fusión psicológica y técnica. | **La Persistencia del S2 (`s2_still_in_prod`):** Una vez asimilado, el motor enemigo es parte de la plataforma principal. Quitarlo destruiría al Eva. Debes mitigarlo operando el SOC sabiendo que tienes una bomba de relojería en la RAM. |

## Anti-patrones Preventivos (Lecciones Reales)
1. **Ingest-as-Upgrade (Celebrar el S2):** Analistas celebrando que ahora el firewall corporativo (Eva-01) tiene "energía infinita" por asimilar la botnet enemiga, ignorando que esa misma asimilación borró los controles de apagado de emergencia (umbilical).
2. **Dummy-Salvage (Forzar la mente con bots):** Creer que puedes resolver una crisis profunda de identidad o *burnout* de tu desarrollador clave lanzando el script automatizado (Dummy) para obligarlo a escupir los commits que se tragó.
3. **Stay-Dissolved (Rehén Útil):** Un gerente como Gendo que decide que un analista disuelto para siempre en el servidor es preferible porque "el servidor ahora vuela y no pide salario", valorando más la herramienta infinita (S2) que la vida humana que la habilitó (Lost_In_Control, exit 14).
