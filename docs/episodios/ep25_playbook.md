```text
[ Inicio: siem.no_pattern_blue ]
        |
        v
[ Instrumentality.start! -> siem.instrumentality_started ]
        |
        +-- (Fallo: New Angel / Dummy / Tabris Alive) ---> [ :instrumentality_denied_skip (Exit 18) ]

```

## Runbook Numerado
1. **Verificación de Radar Limpio:** `no_pattern_blue`. Asegurar que Tabris y Armisael están muertos. Si hay un ángel vivo, el test debe fallar con `Exit 18` (Skip).
2. **Despliegue de Seele:** Se dispara `Instrumentality.start!`. No hay robots gigantes desplegándose en respuesta.
3. **Pérdida de Aislamiento:** El modo del AT Field cambia a `:self` y comienza a colapsar, desencadenando `privacy_zero`.
4. **Interrogatorio Cíclico:** Los operadores entran en una sesión de auditoría existencial profunda. `identity_interrogation` procesa traumas.
5. **La Pregunta Bloqueante:** Se evalúa `do_you_love_me`, deteniendo el avance de la fusión final.
6. **No Fusionar:** Es imperativo no llamar a `complete_merge`. MAGI permanece como tres componentes abstractos observando, no se unen mágicamente aquí.
7. **Resultado Lab:** La traza termina abruptamente con Exit Code 17 (`:instrumentality_in_progress`). El SOC está ciego, el Board sonríe, y el usuario sufre.

## Handoff a Episodio 26 (Take care of yourself)
El suspenso del Exit 17 exige una resolución humana.
*   **La Decisión:** Shinji tiene que decidir si odia estar separado o si quiere "ser él mismo" (I am I).
*   **El Retorno:** La elección devolverá el AT Field y la forma física.
*   **El Aplauso:** El arco y el laboratorio terminarán con "Congratulations".
