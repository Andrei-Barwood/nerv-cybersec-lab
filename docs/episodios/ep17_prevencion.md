# Controles Preventivos: Auditar Lo Propio

## Preventivo vs. Solo Mitigable

| Controles PREVENIBLES (Higiene de Setup) | Controles SOLO MITIGABLES (Deuda hacia el Ep 18) |
| :--- | :--- |
| **No "Skip-Audit" para First-Party:** Establecer cuarentena completa de BIOS, líquido LCL y hardware biológico incluso para Evas fabricados en la sede de Estados Unidos. | **El Hitchhiker Biológico:** Si el contaminante ya viajaba integrado orgánicamente a un nivel nanoscópico indetectable, solo podrá ser contenido tras el despliegue. |
| **Clasificación Cero-Trust de IoCs de Transporte:** Cualquier anomalía eléctrica (`cloud_ioc`) cerca de hardware nuclear en tránsito debe frenar el ingreso, no archivarse como clima. | |
| **Staffing sin Palancas Forzosas:** Reclutar bajo chantaje médico (`sister_leverage`) genera operadores con cero resiliencia psíquica o moral. | |
| **Divulgación de Operador (Need-to-Know Honesto):** Comunicar inmediatamente el nombre del `Fourth Child` a todo el equipo de Respuesta (Shinji, Asuka, Rei) previene fallas de comunicación futuras. | |
| **Validación en HQ previo a Off-site:** Iniciar por primera vez un robot militar complejo en una base aislada como Matsushiro reduce la visibilidad de los analistas de MAGI si algo sale mal. | |

## Anti-patrones Preventivos (Lecciones)
1. **Ours-so-Clean:** La falacia de que el Supply Chain solo afecta software "open source" o proveedores externos (Terceros), y no el código empujado por la sucursal paralela de tu misma empresa.
2. **Need-to-Know como Bondad:** Misato no le dice a Shinji que Toji es el piloto "para proteger sus sentimientos". Esta piedad gerencial ciega al soldado de campo frente al riesgo inminente.
3. **El Dummy Plug (Anti-Prevención):** Gendo y Ritsuko preparan una IA que pueda pilotar el Eva si el humano falla (Ep 18). El Dummy Plug no previene la contaminación de la Unidad-03, solo deshumaniza la respuesta a incidentes. **No es un control, es un arma de doble filo.**
